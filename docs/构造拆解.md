# 《清明上河图》城门楼 —— 构造拆解

本文逐构件说明模型的构造依据、宋代名称、尺寸取值与在原画中的位置，
以及脚本中的实现位置。所有尺寸以米为单位，按《营造法式》材份制折算
（**1 分 = 1.8 cm，材 = 15 分 = 27 cm，足材 = 21 分 = 37.8 cm，栔 = 6 分**）。

---

## 0. 考证：原画中究竟是什么形制

先把原图放大逐块判读（放大件见 `crops/`），免得凭印象做错形式：

| 判读项 | 结论 | 依据 |
|---|---|---|
| 屋顶形式 | **单檐歇山顶**（不是重檐） | `crops/E_topleft.png` 屋顶全貌只见一道正脊、一层斗拱、一条檐口，无腰檐 |
| 正脊两端 | **鸱吻**，头向内卷 | `crops/E_topleft.png` 左上角吻兽轮廓 |
| 山面 | **山花 + 博风板 + 悬鱼** | `crops/A_roof.png` 左侧山花三角形与其上的博风板 |
| 戗脊 | 自收山点斜下至翼角，脊上列**蹲兽** | `crops/A_roof.png` 右上、`crops/F_roofright.png` |
| 檐角 | 明显**起翘、冲出** | `crops/F_roofright.png` 右侧檐角上翻 |
| 斗拱 | **五铺作单抄单下昂**（两跳，第二跳为昂） | `crops/E_topleft.png` 斗拱带可辨栌斗、华拱、斜下的昂、层层散斗 |
| 楼身 | **面阔三间**：窗 · 门 · 窗 | `crops/B_dougong.png` |
| 窗 | **破子棂窗**（密排细竖线） | `crops/B_dougong.png` 次间两片细密竖线带 |
| 栏杆 | **勾栏**：寻杖 + 蜀柱 + 云栱 + 华版 + 地栿 + 望柱 | `crops/B_dougong.png`、`crops/D_stairs.png` |
| 门洞 | **圭形过梁式**，非券顶：两壁斜收、顶上横压木过梁 | `crops/C_gate.png` 门洞两侧壁明显内斜，顶部为水平过梁 |
| 城台 | 四面**收分**（下大上小），墙面排斜向砖纹 | `crops/C_gate.png`、`crops/4_base_wall.png` |
| 踏道 | 沿城台侧面斜上，两侧围勾栏 | `crops/D_stairs.png` |

> 原画坐标（1500×1400）对照：
> 正脊与鸱吻 x≈195–390, y≈10–60；檐口瓦当 y≈215–245；斗拱带 y≈250–345；
> 阑额 y≈345–365；破子棂窗与门 y≈330–405；勾栏 y≈390–460；
> 门洞与门额匾 x≈510–690, y≈460–960；踏道勾栏 x≈0–250, y≈420–800。

## 1. 城台

原画中那面布满**斜向排线**的实墙，是夯土包砖的城台本体。

| 构件 | 尺寸 | 说明 | 实现 |
|---|---|---|---|
| 城台本体 | 30.0 × 14.0 × 10.5 | 四面收分 5.5%，顶面收至 28.8 × 12.8 | `parts/base.py: build_platform` |
| 收分 | 每升高 1 m 每侧内收 0.055 m | 宋城「城身收分」的常见取值 | `common.py: Base.batter` |
| 门洞 | 下宽 5.2 / 上宽 4.4 / 净高 6.6 | 圭形过梁式，非券顶 | `parts/base.py` 挖切体 |
| 壁柱 | 四角 + 门洞两侧 | 原画中那几条明显竖向明暗带 | `parts/base.py: pilasters` |
| 墙面排线 | — | 复刻原画的城砖画法 | `materials.py` 的 `hatch` 层（Wave 纹理绕 Y 轴转 −38°） |

门洞内壁单独指派 `门洞内` 材质（墨更浓、AO 更强），使洞口自然压暗，
与原画中门洞的深色一致。

## 2. 门洞与门扉

**圭形过梁式**是宋代城门的主流做法：门洞两侧壁向上内斜，顶上横压一根木过梁，
而不是后世常见的砖券。原画 `crops/C_gate.png` 里门洞轮廓正是这个形状。

| 构件 | 尺寸 | 原画位置 |
|---|---|---|
| 门洞下口宽 | 5.20 | 洞口底部 |
| 门洞上口宽 | 4.40 | 洞口顶部 |
| 门洞净高 | 6.60 | 至过梁下皮 |
| 过梁 | 高 0.72 × 厚 0.55，长出口 1.6 | 洞口上方那道横木 |
| 门簪 | 4 枚，⌀0.20 × 长 0.34 | 过梁上外挑的木栓 |
| 门额匾 | 3.30 × 1.70，上缘外倾 9° | 原画 x≈510–690, y≈460–600 的倾斜方框 |
| 门扉 | 单扇 2.10 × 4.80 × 0.13 | 每扇 12 枚门钉 + 铺首衔环 |

门扉**向内敞开约 102°、贴靠门洞两壁** —— 这正是原画门洞里那两条深色竖带的由来。
两扇门在 3D 中可以看到背面与门钉，从门洞内往外看则见铺首。

## 6. 铺作（斗拱）

全楼最精彩、也最难做对的部分。判读为 **五铺作单抄单下昂**：
出跳两跳，第一跳华拱（横拱），第二跳昂（斜向下出的斜构件），
自栌斗起共铺叠五层，故名「五铺作」。

**尺寸（《营造法式》卷四·斗拱，全部按材份）**

| 构件 | 材份 | 米 |
|---|---|---|
| 栌斗 | 方 32 分 × 高 20 分 | 0.576 × 0.360 |
| 交互斗 | 长 18 × 高 10 × 宽 16 分 | 0.324 × 0.180 × 0.288 |
| 散斗 | 长 16 × 高 10 × 宽 14 分 | 0.288 × 0.180 × 0.252 |
| 华拱 | 长 72 分 × 足材 21 分 | 1.296 × 0.378 |
| 泥道拱 | 长 62 分 × 单材 15 分 | 1.116 × 0.270 |
| 瓜子拱 | 长 62 分 × 单材 | 1.116 × 0.270 |
| 慢拱 | 长 92 分 × 单材 | 1.656 × 0.270 |
| 令拱 | 长 72 分 × 单材 | 1.296 × 0.270 |
| 拱厚 | 10 分 | 0.180 |
| 出跳 | 30 分 | 0.540 |
| 昂斜度 | — | tan⁻¹ ≈ 19° |

**竖向定位不做手填**，全部由「出跳 30 分、跳高足材 21 分」推导：

```
栌斗 0 → 0.360
华拱 0.360 → 0.738（足材）
交互斗 0.738 → 0.918
昂   坐于交互斗，沿斜率 ·344 斜下 —— ang_under(x) / ang_top(x) 两个函数给出脊线
令拱 坐于昂背（标高由 ang_top(X_LINGGONG) 反算）
散斗 → 撩檐枋底
```

这样改任何一个材份尺寸，整攒铺作会自动重新对位。`parts/bracket.py` 中的
`ang_under()` / `ang_top()` 是关键。

**布列**：柱头铺作骑于柱头，补间铺作在每间（明间两朵、次间一朵），
与原画斗拱带的疏密节奏相合；两山亦布列。合计 520 件构件。
各攒按所在檐面旋转，使局部 +X（出跳方向）指向室外。

**撩檐枋**：檐下一圈通长枋，把各攒铺作连成整体，屋面即由此起坡。

## 7. 屋顶（单檐歇山顶）

**几何构成**：歇山 = 庑殿被两个竖直山花面截断。因此拆成四类曲面：

| 曲面 | 平面形状 | 数量 | 代码 |
|---|---|---|---|
| 前后坡 | 矩形 + 下接梯形（五边形） | 2 | `roof.py: _main_slope` |
| 撒头 | 两端小坡面，自山花下缘斜降至端部檐口 | 2 | `roof.py: _saotou` |
| 山花 | 竖直三角形 | 2 | `roof.py: _gable` |
| 正脊/垂脊/戗脊 | 沿折线放样 | — | `roof.py: bar_along` |

四片曲面**两两共边**：撒头的内边界恰是主坡的戗脊线，
标高统一由举折曲线 `R(d)` 给出，因此天然连续、不会开裂。

| 参数 | 取值 | 说明 |
|---|---|---|
| 出檐 | 自檐柱轴线外挑 2.85 | |
| 举高 | 4.60 | 平均坡度 ≈ 33° |
| 举折指数 | 1.42 | >1 使屋面凹曲：脊部陡、檐部缓，即「举折」之形 |
| 正脊长 | 11.00 | |
| 收山 | 0.45 × 半进深 | 决定垂脊下端位置 |
| 瓦垄间距 | 0.33 | 筒瓦半径 0.105 |
| 翼角起翘 | 1.05，影响范围檐口边长的 34% | |
| 翼角冲出 | 0.55 | |

**瓦垄**：不靠贴图，而是给屋面网格**沿曲面法线做周期位移** ——
一个周期内 58% 为半圆筒瓦、其余为板瓦平段（`roof.py: tile_dz`）。
主坡的瓦垄平行于正脊排列，撒头的瓦垄平行于端部檐口，
与真实屋面的铺瓦方向一致。

**檐口**：每垄筒瓦端头加**瓦当**（圆盘），垄间加**滴水**（下垂尖舌）。

**脊饰**：正脊两端鸱吻（向内卷的轮廓，`chiwen_profile`）；
垂脊自正脊端沿山花边缘下行至收山点；戗脊自收山点斜下至翼角，
其上列 4 只**蹲兽**；山花面装**博风板**，顶点悬**悬鱼**；翼角下加**角梁**。

## 8. 水墨材质与毛笔描边

这是「保留毛笔质感」的实现核心，分两条路：

### 8.1 材质层（`scripts/materials.py`）

几何只负责「形」，墨色全部由着色器生成。每个材质的墨量是四层叠加：

```
墨量 = AO聚墨 + 轮廓积墨 + 皴法 + 飞白 (+ 排线 / 瓦垄接缝)
```

| 层 | 节点 | 对应画法 |
|---|---|---|
| 聚墨 | Ambient Occlusion，取反 | 墨自然沉积在凹处与构件交接处 —— 即**皴染** |
| 积墨 | Layer Weight（Fresnel） | 形体转折处加浓，模拟**顿笔** |
| 皴法 | 中频 Noise | 让墨色不匀 |
| 飞白 | 沿一个方向拉长的高频 Noise | 模拟**干笔**擦过绢面的断续 |
| 排线 | Wave 纹理绕 Y 轴 −38° | 复刻城台墙面的**斜向砖纹** |

墨量再经一条曲线映射（墨分五色），在绢本底色与墨色之间插值，
只有最浓的一小片再压一层焦墨（不做这一步整幅会闷黑）。

底色取自原画实测（`tools/img_tools.py palette`）：
绢本亮部、暖褐的墨色、浓墨、印泥朱红。

### 8.2 描边层（`scripts/render.py` + `scripts/brush.py`）

用 Freestyle 分三层画线，对应白描的主次分明：

| 层 | 选取 | 相对线宽 |
|---|---|---|
| 主轮廓 | silhouette / border / external contour | 1.35 |
| 结构线 | crease / ridge-valley / suggestive contour | 0.62 |
| 材质界 | material boundary | 0.34 |

笔触不是等宽黑线，而是三层叠加的结果：

1. **毛笔笔触位图**（`brush.py: brush_stroke_bitmap`）——
   程序化生成一张「中间浓、两侧枯、纵向带飞白」的笔触图，挂到线型的
   texture slot 上，沿笔画方向平铺。
2. **Calligraphy 修饰器** —— 按笔画走向调制线宽，模拟**笔锋**侧锋行笔。
3. **AlongStroke 修饰器** —— 起笔略重、收笔渐尖，模拟**起收**。
4. **Noise 修饰器** —— 沿途随机粗细，模拟**顿挫**。

> ⚠️ **踩过的坑（都是实测出来的，不是查文档猜的）**
>
> 1. 三个修饰器的 `thickness_min/max`、`value_min/max`、`amplitude`
>    都是**绝对线宽**（与 `linestyle.thickness` 同单位），不是倍率。
>    填倍率会把线压到亚像素，笔画被整片丢弃，渲染日志表现为 `strokes set empty`。
>
> 2. `FreestyleLineSet.select_by_face_marks = True` 时，若网格上没有 face mark，
>    **所有边都会被排除**，笔画全空。必须置 False。
>
> 3. `scene.render.use_freestyle` 与 `view_layer.use_freestyle` **两个开关都要开**，
>    只开一个不生效。且开启时若存在 `linestyle` 为 None 的 lineset，渲染会崩溃。
>
> 4. `fs.crease_angle` 的判据是**法线夹角 > 180° − crease_angle** 才算折边
>    （实测：立方体 90° 边在 crease_angle=90° 起出现；波浪面 53° 的相邻面
>    在 122° 时不出现、135° 时出现）。取 **122°**，构件交接的硬边保留，
>    瓦垄这类连续起伏不画 —— 取默认的 152° 会把每道瓦楞都描一遍，屋面全黑。
>
> 5. `fs.use_ridges_and_valleys = True` + `select_ridge_valley` 会把**每道瓦垄的垄脊**
>    都判成山脊画出来，屋面糊成一张网。本项目置 False。

最后经合成器叠**绢本底纹**（细密经纬交织 + 陈年色斑 + 纤维）、
四角压暗、轻微暖调。

## 9. 标高链

```
城台顶        10.50

檐口          18.51   = 普拍枋上皮 + 铺作层 1.80 + 0.10
正脊          23.11   = 檐口 + 举高 4.60
```

## 10. 文件与运行

```
scripts/
  common.py        全局参数（材份制、城台/门洞/楼身/屋顶/勾栏/踏道）与几何工具
  materials.py     水墨材质工厂
  brush.py         程序化笔触图 / 绢本底纹 / 暗角图
  render.py        渲染、Freestyle 毛笔描边、合成、机位
  build_gate.py    总装与导出
  render_views.py  出图入口
  parts/
    base.py        城台、门洞、门扉、门额、壁柱、踏道
    bracket.py     铺作
    frame.py       檐柱、阑额、普拍枋、破子棂窗、门、平坐
    railing.py     勾栏
    roof.py        歇山顶
tools/
  img_tools.py     在原图上量取坐标 / 裁切放大 / 取色（供考证）
```

```bash
# 只建模 + 导出
Blender --background --python scripts/build_gate.py

# 建模 + 出全部效果图（快 / 高 两档画质）
Blender --background --python scripts/render_views.py -- 快 1100 820
Blender --background --python scripts/render_views.py -- 高 2000 1450
```

## 11. 已知取舍

- **斗拱未做「卷杀」的细节分段**：拱头卷杀按连续曲线生成，未按《法式》
  逐分折减；远看无差，贴面看略简化。
